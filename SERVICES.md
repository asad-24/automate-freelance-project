## What is working RIGHT NOW (live, today)

| Part | Status | Where it runs |
|---|---|---|
| Website (frontend) | ✅ Live | Vercel — https://autopilotv2.vercel.app |
| Backend (the brain) | ✅ Live | Render — https://autopilot-1tjw.onrender.com |
| Database | ✅ Live | MongoDB Atlas (free cluster) — signups & all data persist |
| Real accounts | ✅ Working | Sign up → saved in MongoDB → log in with real credentials |
| Agent command center | ✅ Working | Run agents, consoles, live activity, audit log |
| AI-written bids | ✅ Working | Proposals & outreach generated by Groq (`gpt-oss-120b`, free tier) |
| **Job Radar** | ✅ Working | Finds real live jobs from 5 free sources, ranks by skill match, AI writes the proposal → review → copy & apply (semi-automated, no account risk) |
| **AI Gig Builder** | ✅ Working | One click writes a complete Fiverr/Upwork gig — titles, description, 3-tier pricing, tags, buyer FAQ → review & paste to publish |
| Connector hub | ✅ Working | Connect Upwork/Fiverr/LinkedIn/Reddit/Facebook profiles, publish gigs, unified applications tracker |
| Free plan & credits | ✅ Working | 10 free bids + 2 profiles → paywall → top-ups/Pro (simulated checkout) |
| Clients/bids/messages | ✅ Working | Agents generate proposals, conversations, contracts — all visible |

**Cost so far: $0** — everything runs on free tiers.

### For REAL marketplace automation (platform-by-platform plan)

> Founder-approved strategy: each platform gets its own approach instead of
> one generic bot. What's ALREADY built handles the content side for free.

**Already live & free:**
- **Fiverr** — sellers don't bid; buyers find gigs. Covered by **AI Gig Builder**
  (auto-writes the whole listing — paste & publish) + Job Radar for leads.
  Next step for deeper automation: gig posting/messaging assistant.
- **Upwork** — has an **official API** (job search + proposals). Requires an
  established account ($25k+ earnings, 90%+ JSS) for API keys — apply when a
  qualifying account is available; until then Job Radar covers discovery and
  AI covers proposals.
- **Everywhere else** — case-by-case sources already added: Freelancer.com
  official API, Reddit, RemoteOK, WeWorkRemotely, Hacker News (all free).
